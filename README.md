## ⚡ Core Features

1. **Step 1: Stream Pre-Selection Menu:**
   - Interactive prompt: *"What type of university are you targeting?"*
   - Dedicated streams:
     - 🩺 **Medical & Dental (MBBS / BDS):** UHS Punjab, NUMS (Army Medical College AMC & CMH), Dow / DUHS Sindh, KMU KPK, Aga Khan University (AKU), and Shifa Tameer-e-Millat (STMU).
     - 💻 **Computing & Software:** FAST-NUCES, NUST SEECS, LUMS SBASSE, IBA Karachi, COMSATS, GIKI, PUCIT, UET Lahore, NED Karachi, PIEAS Islamabad, SSUET, FCCU, and BNU.
     - ⚙️ **Engineering & Tech (PEC):** NUST, GIKI, UET Lahore, NED Karachi, PIEAS Islamabad, SSUET Karachi, FAST Engineering, COMSATS Engineering, and LUMS.
     - 📊 **Business & Management:** IBA Karachi, LUMS SDSB, NUST NBS, FAST Business, COMSATS Business, FCCU, and BNU.
     - 🌐 **All Universities & Fields:** Comprehensive simultaneous view across all 25+ institutions.
   - **Multi-Discipline Transparency:** Universities with multiple faculties (e.g. NUST, FAST, LUMS, COMSATS, GIKI, UET, NED, PIEAS, SSUET, FCCU, BNU) appear in every field they offer.

2. **National MDCAT & PMDC Regulatory Integration:**
   - **Standard PMDC Formula:** $50\% \text{ MDCAT (out of 200)} + 40\% \text{ FSc Pre-Medical} + 10\% \text{ Matric}$.
   - **Hafiz-e-Quran Policy:** 20 marks added directly to FSc marks before percentage computation.
   - **Live PMDC Status Evaluation:** Real-time feedback for MBBS cutoff ($\ge 55\%$, 110 marks) and BDS cutoff ($\ge 50\%$, 100 marks).
   - Universal MDCAT mapping: Entering your MDCAT score once automatically evaluates merit across all affiliated public and private medical colleges.

3. **Curriculum Schemes (1100 vs 1200 Marks):**
   - **New Punjab Boards & FBISE:** Accounts for compulsory **Tarjuma-tul-Quran (100 marks)** raising total marks from 1100 to 1200 (50 marks in Part-1, 50 in Part-2) and Matric to 1200.
   - **Traditional & Other Boards:** Presets for traditional 1100 marks (Sindh, KPK, Pre-2024 repeaters) and Part-1 marks (520 for FBISE, 550 for Punjab).

4. **NUST Gap Year Policy Clarification (0% Deduction):**
   - Official NUST Rule: **0% deduction** for gap-year candidates. Fresh candidates apply with Part-1, while gap-year applicants use full FSc on 100% equal footing.
   - Contrasted with Punjab University (PUCIT) which officially deducts 2 marks per late session (gap year).

5. **Digital SAT (1600 Scale) Evaluation:**
   - Scaled SAT calculations for FAST (CS/Eng min 1200, Business min 1000), NUST National Seats (75% SAT), LUMS, IBA Karachi (test exemption for $\ge 1400$ CS, $\ge 1270$ BBA), GIKI (85% SAT), and COMSATS (50% SAT).

6. **Reverse Target Score Solver ("What score do I need?"):**
   - Derived mathematically to solve the exact minimum test score required in **MDCAT (out of 200)**, **NET (out of 200)**, **FAST NU Test (out of 100)**, **ECAT (out of 400)**, **NED Test (out of 100)**, or **Digital SAT (out of 1600)** to achieve your target aggregate.

7. **IBCC O/A-Level Equivalence Modal:**
   - Standard 8-subject grade selector ($A^*=90, A=85, B=75, C=65, D=55, E=45$) with 1-click form auto-population.

8. **Direct Official Admission Portal Redirects:**
   - Every university card features an **Official Portal ↗** button linking directly to verified university undergraduate admissions portals.

## 🌐 How to Deploy for Free ($0 Budget)

This project is a static Single Page Application built with React 19, TypeScript, and Vite. It requires **zero backend servers, microservices, or databases**, making it completely free to host forever:

### Option 1: Vercel (Recommended — 2 Minutes, Zero Configuration)
1. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New..."** → **"Project"**.
3. Select the repository: `AbdulRaheem2004/UniMerit-CalculatorPk`.
4. Vite framework preset will be auto-detected:
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. Click **"Deploy"**. Your application will be live globally on CDN with SSL.

### Option 2: Cloudflare Pages
1. Go to [pages.cloudflare.com](https://pages.cloudflare.com) and connect your GitHub repository.
2. Build setting: Framework `Vite`, Build command `npm run build`, Output directory `dist`.
3. Click **"Save and Deploy"**.

### Option 3: GitHub Pages
1. In repository settings, navigate to **Pages**.
2. Under **Build and deployment**, select **GitHub Actions** with the static Vite workflow.
